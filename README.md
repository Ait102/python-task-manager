# python-task-manager

Консольный менеджер задач на Python. Учебный проект для практики работы с ветками Git.

## Возможности

- добавить задачу;
- показать список задач;
- отметить задачу выполненной;
- удалить задачу.

## Запуск

```bash
python src/main.py
```

## Тесты

```bash
pip install -r requirements.txt
python -m pytest
```
