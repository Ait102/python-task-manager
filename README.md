# Python Task Manager (TaskMan)

Консольный менеджер задач на Python: ведение списка дел прямо из командной строки, без браузера и сторонних сервисов.

## Описание

Python Task Manager помогает не забывать о делах: задачи добавляются, отмечаются выполненными, удаляются, их можно искать и фильтровать. Список задач сохраняется в файл `tasks.json` и загружается при следующем запуске.

Проект создан как учебный для практики работы с Git: ветками, слиянием (merge), перебазированием (rebase), разрешением конфликтов и Pull Request.

## Возможности

| № | Пункт меню | Что делает | Функция в коде |
|---|---|---|---|
| 1 | Добавить задачу | создаёт задачу с проверкой названия (не пустое, не длиннее 100 символов) | `add_task` |
| 2 | Показать задачи | выводит все задачи с отметкой `[x]` / `[ ]` | `list_tasks` |
| 3 | Отметить выполненной | помечает задачу по номеру | `complete_task` |
| 4 | Удалить задачу | удаляет задачу по номеру | `delete_task` |
| 5 | Найти задачу | ищет по части названия без учёта регистра | `search_tasks` |
| 6 | Выполненные / невыполненные | фильтрует задачи по статусу | `filter_tasks` |
| 7 | Статистика | показывает, сколько задач всего, выполнено и осталось | `get_stats` |
| 0 | Выход | сохраняет задачи и завершает программу | `save_tasks` |

Дополнительно:

- неверный ввод (пустое название, буквы вместо номера) выводит понятное сообщение и не завершает программу;
- задачи автоматически сохраняются в `tasks.json` после каждого действия.

## Требования

- Python 3.10 или новее;
- pip (входит в состав Python);
- Git — чтобы клонировать репозиторий.

Сама программа использует только стандартную библиотеку Python. Внешняя библиотека pytest нужна только для запуска тестов.

## Установка

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/Ait102/python-task-manager.git
   cd python-task-manager
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   venv\Scripts\activate          # Windows (cmd / PowerShell)
   source venv/bin/activate       # Linux / macOS
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## Запуск

```bash
python src/main.py
```

Запуск тестов:

```bash
python -m pytest
```

## Использование

После запуска программа показывает меню. Нужно ввести номер пункта и нажать Enter.

```text
=== Python Task Manager v1.2.0 ===
1. Добавить задачу
2. Показать задачи
3. Отметить выполненной
4. Удалить задачу
5. Найти задачу
6. Показать выполненные / невыполненные
7. Статистика
0. Выход

Выберите пункт: 1
Название задачи: Купить хлеб
Добавлено: [ ] 1. Купить хлеб

Выберите пункт: 1
Название задачи: Сдать ЛР4
Добавлено: [ ] 2. Сдать ЛР4

Выберите пункт: 3
Номер задачи: abc
Ошибка: Номер задачи должен быть целым числом

Выберите пункт: 3
Номер задачи: 1
Готово.

Выберите пункт: 5
Что искать: лр
[ ] 2. Сдать ЛР4

Выберите пункт: 7
Всего: 2, выполнено: 1, осталось: 1

Выберите пункт: 0
Задачи сохранены. До свидания!
```

(Меню между шагами в примере опущено.)
